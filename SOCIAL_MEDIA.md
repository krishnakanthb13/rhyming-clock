## 👽 Reddit Post
**Target Subreddits**: `r/selfhosted`, `r/retrocomputing`, `r/javascript`, `r/opensource`

```text
Title: [Show off] Rhyming Clock v1.3.7 - A retro-styled AI clock widget now on Windows, macOS, & Linux

Hey everyone,

I wanted to share a major update (v1.3.7) to **Rhyming Clock**, a minimalist retro desktop widget that uses Gemini AI to generate a unique 2-line rhyming poem for every single minute of the day.

The interface is styled like a classic glowing CRT monitor with scanlines, a mechanical typing effect, audio-sound effects, and customizable time-based personalities (the clock's mood gets a little kinky at night 🌙).

Key Updates from v1.3.2 to v1.3.7:
1. **Cross-Platform Launchers**: We now support Linux and macOS! Both Windows (`.bat`) and Linux/macOS (`.sh`) launchers feature automatic `.env` creation.
2. **Upgraded AI Engine**: Switched to the lightweight `gemma-4-26b-a4b-it` model.
3. **Smart Rate-Limiting**: The clock automatically tracks API requests using a local sliding window stored in `localStorage` to stay under the 15 req/min free-tier limit.
4. **Hardened API Calls**: API keys are now securely passed in HTTP headers rather than URL query parameters, and we added capped exponential backoff to handle transient API issues.
5. **TTS and Offline Fallbacks**: If you exceed your quota or lose internet, it falls back to an offline library. It also supports local Text-to-Speech (TTS) using the Web Speech API.

It's entirely client-side HTML/JS, running in a tiny frameless window (300x200). 

Github Repository: https://github.com/krishnakanthb13/rhyming-clock

Feedback and contributions are very welcome!
```
